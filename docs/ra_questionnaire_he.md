## חלק א — מבנה הסריקה והעמודים

### א.1 חלוקת עמודים לפי סוג
ציינו טווחי עמודים *לפי מספר הסריקה* (לא לפי מספור הספר המקורי). השתמשו בפסיקים או מקפים: "1-3, 5".

- **עמודי שער (titlePage):** עמודים מס' …
- **עמודי רשימת דמויות (castList):** עמודים מס' …
- **עמודי גוף המחזה (body):** עמודים מס' …
- **עמודי שער אחורי / מודעה / מידע מו"ל:** עמודים מס' …
- **עמודים ריקים:** עמודים מס' …

### א.2 בעיות סריקה ידועות
האם יש עמודים שצריכים טיפול מיוחד?

- **עמודים כפולים (אותו תוכן בשתי סריקות):** ציינו זוגות, למשל "3 = 18".
- **עמודים שנסרקו לא במקום הנכון בספר (binding error):** עמוד X בסריקה הוא בעצם עמוד Y במחזה המקורי.
- **עמודים חסרים:** מספרי עמודים מהמחזה המקורי שאינם בסריקה.
- **עמודים ריקים שדורשים מחיקה מהצינור:** כתבו את המספרים.

## חלק ג — הדמויות (cast list)

לכל דמות במחזה:

### ג.1 רשימת דמויות
| שם בעלילה (יידיש מלא, מנוקד) | שם מקוצר/קנוני בכותרות דיבור | xml:id מוצע (אנגלית, lowercase) | תיאור התפקיד (יידיש) |
|------------------------------|------------------------------|--------------------------------|----------------------|
| | | | |

**הסבר**: ה"שם הקנוני" הוא איך הדמות מסומנת כשהיא מציגה דיבור (לפני נקודתיים). למשל במחזה Der Mann Unterm Tisch:
- סאָבֶּעֶלעֶ (בגוף הטקסט) → סאבּעלע (בכותרת דיבור — רק דגש בבי״ת)
- טוּרְנִיווער (בגוף הטקסט) → טוּרניווער (בכותרת דיבור — רק שורוק בו״ו ראשון)

## חלק ו — בדיקת תיוג (annotation) לפני העלאה ל-Transkribus

לאחר שהצינור של התיוג רץ ויצר את `page_annotated/`, אנא:

### ו.1 דוגמה רוחבית
פתחו 3 עמודים מייצגים (עמוד שער, עמוד רשימת דמויות, עמוד גוף טיפוסי) וענו:

- **האם סוג העמוד (`structure type=...`) נכון בכולם?**
- **האם כותרות הדיבור (`speaker`) מסומנות במקום הנכון?** ציינו עמוד/שורה אם לא.
- **האם הוראות הבימוי (`stage`) מסומנות במקום הנכון?** ציינו עמוד/שורה אם לא.

## חלק ז — נכונות לבדיקה ב-Transkribus

לפני העלאה לבדיקה אנושית ב-Transkribus, ודאו:

- [ ] תגיות מותאמות (`speaker`, `stage`, `heading`, `castItem`) הוגדרו ב-tag schema של ה-collection.
