How to read a row. A blue edge is a confirmed link carrying a database id. An amber edge is an automatic proposal — order-insensitive token matching, which is what the catalogue's “Surname, Given” against people_db's “Given Surname” requires — and it is a suggestion, not a decision. A red edge is an open question: no candidate, several equally good ones, or a match too weak to trust.
