# מדריך לסקירה אנושית של מחזות מסומנים — לנועה

ברוכה הבאה לפרויקט YiDraCor. המסמך הזה מתאר בקצרה מה מסומן בעמודי ה-PAGE-XML של המחזות שעברו אנוטציה אוטומטית, ומה ספציפית את צריכה לבדוק כשאת עוברת על כל עמוד.

המחזות שמחכים לסקירה (במצב הנוכחי):
- **Yudale der Blinder** (Yudale_der_blinder,_Emkroyt1908) — 70 עמודים
- **Di Seder Nakht** (Di_seyder_nakht_Emkroyt_1908) — 72 עמודים
- **Das Yudishe Kind** (דאס_יידישע_קינד_Dos_yudishe_kind_a_komishe_operete) — 12 עמודים שעברו OCR (60 בסך הכול)
- **Der Mann untern Tisch** (DerManUnterTiff) — 19 עמודים, כבר ב-DraCor

הסקירה מתבצעת ב-Transkribus, בקובץ ה-PAGE-XML של כל עמוד. ה-tags מופיעים בשדה `custom` של כל `TextLine` או `TextRegion`.

---

## 1. סוגי האלמנטים (Tags)

### ברמת ה-Region (אזור טקסט בעמוד)

| Tag | משמעות |
|---|---|
| `structure {type:titlePage}` | עמוד שער — אמור להופיע פעם אחת בלבד בכל מחזה (לרוב עמוד 1 או 3) |
| `structure {type:castList}` | רשימת הדמויות (Dramatis Personae) |
| `structure {type:body}` | גוף המחזה (דיאלוגים, הוראות במה, וכו') |
| `structure {type:paragraph}` | סימון פסקה רגיל בתוך גוף |

### ברמת השורה (TextLine)

| Tag | משמעות | דוגמה |
|---|---|---|
| `speaker` | שם הדובר בתחילת שורה (לפני נקודתיים) | `ירוחם:` |
| `stage` | הוראת במה (בדרך כלל בסוגריים) | `(זינגט)`, `(אב)` |
| `heading` | כותרת של מערכה או סצנה | `ערשטער אקט`, `סצענע צווייטע` |
| `role` | שם הדמות ברשימת הדמויות (רק בעמוד castList) | `יוּדַאלֶע` |
| `roleDesc` | תיאור הדמות לצד שמה (רק בעמוד castList) | `דער בלינדער יתום` |
| `l` | שורת שיר (lyric line) | שורה בודדת בתוך שיר |
| `head` | כותרת של שיר או של בית בתוך שיר | `קופלעי וואסיליע.`, `דועט:`, `I` |
| `lg` | סימון תחילת קבוצת שורות (line group) של שיר בעמוד | מסמן את תחילת השיר בעמוד מסוים |

## 2. תכונות (Attributes) חשובות

כל tag מקבל תכונות בתוך הסוגריים המסולסלים:

- `offset:N` — מהאות הכמה השונה ה-tag מתחיל בתוך השורה (ספירה מ-0)
- `length:N` — כמה תווים ה-tag מכסה
- `xmlid:NAME` — מזהה ייחודי באנגלית של הדמות (למשל `yerukhem`, `zelmen_kahn`). חייב להיות זהה בשורת ה-`role` (ב-castList) ובכל ה-`speaker` של אותה דמות.
- `type:VALUE` — לתת-סוג של `stage` או `heading`:
  - **heading**: `act` (מערכה), `scene` (סצנה)
  - **stage**: `setting` (תיאור פתיחת סצנה), `entrance` (כניסה), `exit` (יציאה), `delivery` (אופן אמירה — `(זינגט)`, `(בכעס)`, `(צו X)`), `business` (פעולה כללית), `location` (מיקום של דמות), `mixed` (מעורב)
- `n:N` — לפריט מספור (`heading n:1` = מערכה ראשונה)
- `lg_id:N` — מזהה של קבוצת השורות שאליה השורה שייכת (קושר `l`, `head` ו-`lg` שמשתייכים לאותו שיר)
- `continued:no|yes` — ב-`lg` בלבד: האם זו תחילת השיר (no) או המשך משיר שהתחיל בעמוד הקודם (yes). שירים שעוברים בין עמודים מקבלים `lg` חדש בכל עמוד עם `continued:yes` בעמודי ההמשך.

דוגמה לשורה מסומנת כדובר:
```
custom="readingOrder {index:5;} speaker {offset:0; length:5; xmlid:yerukhem;}"
```

דוגמה לשורה מסומנת כדובר + הוראת במה באותה שורה:
```
custom="readingOrder {index:5;} speaker {offset:0; length:5; xmlid:yerukhem;} stage {offset:7; length:5; type:delivery;}"
```

## 3. רשימת בדיקות — מה ספציפית לבדוק בכל עמוד

### א. עמוד שער (titlePage)
- [ ] יש בדיוק עמוד שער **אחד** במחזה (בדרך כלל עמ' 1 או 3)
- [ ] עמודי כריכה ריקים (שאין בהם טקסט) — הוסרו לחלוטין; ה-`structure` שלהם איננו אמור להופיע
- [ ] עמודי back-matter (פרסומות, קטלוגים, OCR פגום בסוף הספר) — אמורים להיות מחוקים לגמרי

### ב. רשימת הדמויות (castList)
- [ ] לכל שם בעמוד יש tag של `role` עם `xmlid` ייחודי
- [ ] התיאור שלצד השם (אם יש) מסומן כ-`roleDesc`
- [ ] השמות מתאימים לשמות שמופיעים ב-`speaker` בגוף המחזה
- [ ] הדמויות שמדברות בגוף המחזה ולא מופיעות ברשימה — מסומנות בקובץ `cast_dict.json` עם `source: editorial` (אלה דמויות שהוספנו עורכתית, כמו `fishl` ב-Yudale, `helpgot` ו-`kor` ב-DSN, `kor` ב-DYK, `dyener` ב-DSN)

### ג. גוף המחזה (body)
לכל שורה שמתחילה בשם דמות ולאחריו נקודתיים (`X:`):
- [ ] יש `speaker` tag עם `xmlid` הנכון
- [ ] ה-`length` של ה-tag כולל **רק את השם, ללא הנקודתיים והרווח שאחריהם**
- [ ] השם מסומן גם אם יש לו ניקוד או צורת קיצור (למשל `הענ:` במקום `הענעלע:` — האם ה-`xmlid` הוא הקנוני?)
- [ ] OCR מוטעה של שמות (למשל `ולמן` במקום `זלמן`, `ירוהם` במקום `ירוחם`) — האם תוקן? אם לא, לתקן את הטקסט בעמוד ה-Transkribus
- [ ] שורות הקבוצה (`אלע:`, `ביידע:`, `דועט:`, `דאמען:`, `מענער:`, `קינדער:`) — **לא** מסומנות כ-`speaker` (אלה אינדיקציות במה, לא דמות יחידנית)

### ד. הוראות במה (stage)
- [ ] כל ביטוי בסוגריים `(...)` מסומן כ-`stage`
- [ ] בדיקה של ה-`type`: 
  - `(אויפטריט X)` → `entrance`
  - `(אב)` או `(X אב)` → `exit`
  - `(זינגט)`, `(בכעס)`, `(צו X)` → `delivery`
  - `(אָרים צימער ביי ירוחם)` (תיאור פתיחת סצנה) → `setting`
  - פעולה כללית → `business`
- [ ] הוראת במה שמשתרעת על כמה שורות (פותחת בסוגריים ב-שורה אחת וסוגרת בשורה אחרת) — כל חלק בכל שורה מסומן בנפרד
- [ ] שורות שכתוב בהן `מען זינגט` ולא תוחמות בסוגריים — בדיקה אם זה stage או חלק מההנחיה הדרמטית

### ה. שירים (l / head / lg)
- [ ] תחילת שיר מסומנת ב-`lg` בשורה הראשונה בעמוד, עם `continued:no` בשיר הראשון או `continued:yes` בעמודי המשך
- [ ] כותרת שיר (למשל `קופלעי וואסיליע.`, `דועט:`) מסומנת כ-`head`
- [ ] סמני בתים בתוך שיר (`I`, `II`, `III`) — בדיקה אם הם מסומנים כ-`head` (אמורים) או כ-`l` (לתקן)
- [ ] שורות מילים של שיר מסומנות כ-`l`
- [ ] שורות שאינן באמת מילות שיר (פתיחות שיר, הסברים בפרוזה כמו `אין ערשטען אקט ווען מאיר דרייער טרעפט זיי`) — האם הן בכלל אמורות להיות בתוך ה-lg, או שהן הוראות במה / כותרות?
- [ ] שירים שכאילו "ממשיכים" לעמוד הבא אבל בעצם הסתיימו — לסגור ידנית (להוריד את ה-`l` משורות שאינן באמת מילים)

### ו. כותרות (heading)
- [ ] כל מערכה (`ערשטער אקט`, `צווייטער אקט`) מסומנת כ-`heading type:act` עם `n` המתאים
- [ ] כל סצנה (`ערשטע סצענע`, `סצענע צווייטע`) מסומנת כ-`heading type:scene` עם `n` המתאים
- [ ] רצף המספור עקבי (מערכה 1, 2, 3... אם יש)

### ז. בעיות OCR לתקן בעת הסקירה
- שמות דמויות שנכתבו בצורה שונה במקומות שונים — לרשום ולתקן בעמוד
- אותיות מתחלפות (`ה/ח`, `ו/ז`, `ד/ר`) בשמות בולטים — לתקן
- שורות חתוכות באמצע מילה — לסמן `<unclear>` או לתקן

---

## 4. מה לא לעשות

- אל תמחקי את ה-`readingOrder` — הוא מסודר אוטומטית
- אל תשני את ה-`xmlid` של דמות שכבר קיימת ברשימת הדמויות — זה ישבור את הקישורים בכל המחזה
- אל תוסיפי דמויות חדשות ישירות לרשימת הדמויות בעמוד castList — אם דמות חסרה, רשמי הערה ונוסיף אותה ל-`cast_dict.json` עם `source: editorial`
- אל תמחקי שורות slowo — אם שורה היא OCR פגום, סמני `<unclear>` במקום למחוק

## 5. שאלות / אי-בהירויות

תרשמי בטבלה נפרדת (Google Sheet או דומה) דברים שלא ברורים, כדי שאני וג'ודית נדע אחר כך:
- שמות דמויות שמופיעות ובעלות OCR לא ברור
- שירים שלא ברור איפה הם מתחילים או נגמרים
- הוראות במה שלא ברור איזה `type` להן
- כל מקרה שבו האנוטציה האוטומטית נראית שגויה
