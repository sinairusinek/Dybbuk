## 1. Why this effort exists

The annotation step had sometimes run on **un-vocalized OCR** instead of the RA's vocalized gold, then pushed that sparse layer to Transkribus, **masking the RA's vocalization** (Transkribus shows only the top layer). Root cause + rule recorded in [[feedback-annotate-from-gold]]: **always annotate from `page_final` gold when it exists; verify nikud density ≈ gold before pushing.**

## 4. Conventions & standards now in force (apply in Phase 4)

- **Annotate from `page_final` gold**, never raw OCR, when gold exists. Verify density ≈ gold before push. [[feedback-annotate-from-gold]]
- **Per-edition vocalization conventions** ([[editions-conventions-2026-05-19]]): DerMann rafe=yes/syllables/strip stage segol-hiriq; Yudale rafe=no/consonants; Di Seder rafe=no/mixed; **Das Yudishe Kind rafe=yes/syllables/speakers VOCALIZED — do NOT strip speaker/stage nikud**; Kidush Hashem & Al Naharot rafe=no/consonants.
- **speaker/stage nikud strip** only within those spans, in page_annotated only, preserve maqaf/punctuation — and ONLY for editions whose convention is unvocalized speakers. [[feedback-unvocalize-spans-scope]]
- **lg = stanza, group model, `cont:yes`-only.** [[transkribus-tagset-cont]]
- **stage `type` required**, no `mixed`; values per §2.
- **page-type marker** on lowest-readingOrder region with lines.
- **Don't mask RA work:** never push a sparser layer over a newer RA layer; re-check `fulldoc` before pushing. [[feedback-pull-masks-gt]]
- **Don't re-push content identical to an RA layer** (no-op guard).
- GUI tagset (Judith, out-of-band): properties `structure→type; speaker→xmlid; role→xmlid; stage→type; heading→type,n,subtype; lg→n,cont; l→lg_id; head→lg_id`. No colons in names. Data round-trips regardless.

- **Env:** Transkribus calls need `source ~/.zshrc &&` (creds in env). Use anaconda **`python`** (3.11) for anything importing `code/annotation/schema.py` (uses `str | None`) or needing `lxml`; the shell's `python3` is 3.9 and will fail. [[reference-transkribus-creds]]
- **Tools:** `code/transkribus/sync.py` (`pull`, `push --file`, `push-dir`; flags `--col --status --parent --dry-run`; reads doc/pageNr from `<TranskribusMetadata>`). `code/annotation/reanchor.py` (`--old --new --out`; matches by TextLine `@id`; keeps structure/readingOrder from `--new`, overlays other spans from `--old`; **exits non-zero when it drops spans** — handle). `extract_cast_dict.py`. `code/vocalization/{pipeline,vocalize_from_reference,dracor_dict,rules,eval_vs_gold}.py`.

- **Status decisions:** GT-restore pages → push **FINAL**, Judith marks GT in UI (API likely won't accept `status=GT` — untested). Pipeline-drafted pages → **IN_PROGRESS**.
- **Network:** `files.transkribus.eu` (file CDN) had a transient DNS failure mid-session while the API host stayed up; retried and it recovered. Add retries on `fetch_transcript`.
- **Backups:** every per-play write was snapshotted to `*_pre_*_2026-05-21/` dirs (e.g. `page_annotated_pre_GTrestore_2026-05-21`, `page_annotated_pre_lgconvert_2026-05-21`, `page_annotated_pre_stanza_2026-05-21`, DerMann `page_*_pre_Noa_2026-05-21`). Keep this habit.
